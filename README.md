# A股 AI 选股系统（Qlib + LightGBM）

用机器学习给 A股大盘蓝筹**每日打分排名、辅助交易决策**的最小可用系统。

- **特征**：微软 Qlib 内置的 **Alpha158**——158 个技术指标（K线形态、均线、动量ROC、波动率、量价相关性、类RSI等）
- **模型**：LightGBM 预测未来 20 个交易日收益，做横截面排序选股（中长线趋势）
- **输出**：每个交易日一份 TopK 选股清单（代码+名称+打分）
- **回测**：TopK 组合策略，计入 A股交易成本、涨跌停限制，并与「等权基准」对标

> ⚠️ 本项目是**决策支持工具**，输出为模型打分排名，**不是投资建议**。务必先模拟盘验证、结合基本面与风控，盈亏自负。


## 快速开始

环境已在 `.venv` 内装好（Python 3.10 + pyqlib 0.9.7 + akshare）。所有命令在 `astock-qlib/` 目录下执行。

```powershell
# 激活虚拟环境
.\.venv\Scripts\Activate.ps1

# 第1步：抓取行情（首次较慢；失败会自动重试，已缓存的会跳过）
python -m src.fetch_data

# 第2步：转成 Qlib 数据格式
python -m src.dump_qlib

# 第3步：训练 + 回测 + 生成最新选股清单
python -m src.train

# 第4步：查看/复盘某日选股清单
python -m src.predict                    # 最新交易日 Top20
python -m src.predict --date 2025-06-30  # 指定历史某日复盘
python -m src.predict --topk 10          # 只看前10
```

**日常使用**：中长线约每月调仓一次。每次想更新时，依次跑 `fetch_data → dump_qlib → train`（train 会自动重新训练并输出最新清单），再用 `predict` 查看。

## 如何看结果

**1. 预测质量（train 输出的 IC/RankIC）**

| 指标 | 含义 | 参考 |
|------|------|------|
| RankIC均值 | 打分与未来收益的排序相关性 | >0.03 有一定选股力，>0.05 较好 |
| RankICIR | RankIC 的稳定性（均值/标准差） | 越高越稳定 |

**2. 回测（train 输出 + `output/backtest_report.csv`）**
- 策略累计收益 vs 基准累计收益：看是否**跑赢**
- 超额年化、信息比率IR：>0 才有超额价值
- 最大回撤：能承受的最大浮亏

**3. 选股清单（`output/latest_picks.csv`）**
- 按模型打分从高到低排序的 TopK 只股票

## ⚠️ 关于当前示例结果（务必阅读）

用内置的 ~60 只大盘蓝筹跑出来的**样例结果通常跑输沪深300**。这不是 bug，原因很实在：

1. **股票池太小**：仅约 60 只时，持仓 20 只≈持有 1/3，几乎没有选择空间；
2. **信号本来就弱**：单纯技术指标的 RankIC 常只有 0.01~0.03，A股噪声大；
3. **风格错配**：示例测试期（2024–2026）大盘价值（银行/资源/红利）领涨，而技术面模型未必偏向它们。

**这恰恰是量化的真相：朴素 ML 很难直接跑赢市场。** 本项目价值在于给你一套**正确、可扩展的管道**，而非一个现成的赚钱策略。

### 如何提升（按性价比排序）
1. **扩大股票池**：把 `universe.py` 换成完整沪深300/中证500（网络允许时可接指数成分接口），股票越多、横截面选股越有效；
2. **加入基本面因子**：估值、成长、盈利质量等（Alpha158 只有量价）；
3. **调参与换模型**：调 `config.LGB_PARAMS`，或试 Qlib 内置的其他模型；
4. **改进标签/调仓**：调 `LABEL_HORIZON`、`TOPK`、`N_DROP`；
5. **滚动重训**：定期用最新数据重训，做真正的样本外滚动验证。

## 常用配置（`config.py`）

| 配置 | 说明 |
|------|------|
| `MAX_STOCKS` | 限制股票池大小；`None`=用内置清单全部 |
| `START_DATE` | 数据起始日 |
| `LABEL_HORIZON` | 预测未来多少交易日的收益（默认20≈1个月） |
| `TRAIN/VALID/TEST_PERIOD` | 训练/验证/测试的日期切分（严格防未来函数） |
| `TOPK` / `N_DROP` | 持仓只数 / 每次最多换手只数 |
| `OPEN_COST/CLOSE_COST` | 买入/卖出费率（含印花税） |
| `LGB_PARAMS` | LightGBM 超参 |

## 数据说明

- 数据源：**AkShare**（东方财富接口），前复权日线；
- 若你的网络访问不了指数成分股接口，本项目已改用**内置蓝筹清单 + 合成等权基准**，无需这些接口；
- 抓取带自动重试；单只失败会跳过、不影响整体；已缓存的会跳过（增量）。

## 已知限制
- 内置股票池为**当前**成分，存在轻微幸存者偏差（未做成分股历史回溯）；
- 合成基准是股票池等权指数，非真实沪深300指数；
- Qlib 训练时会打印若干 `CatBoost/XGB/PyTorch skipped` 与 gym 警告，**均无害**（未安装的可选模型）。
