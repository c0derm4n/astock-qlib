# 剔除纳指后的30只ETF策略研究计划

目标：完全排除513100纳指ETF，在原池剩余30只ETF中寻找扣除交易成本后，累计收益与年化接近标普500的可执行策略。

## 预先固定的研究与验收口径

- 区间：2016-01-05至2026-09-11；2021-01-04重新以现金建仓至2026-09-11。两个区间均须达标，保留所有失败结果。
- 主基准：SPY分红再投资代理，按同期USD/CNY折成人民币；并列美元全收益与标普价格指数。复用已交叉核对的独立基准快照。
- 接近标准：年化落后不超过2个百分点，累计收益至少达到人民币SPY的85%。不更改起止日或降低基准。
- 风险：不杠杆、不做空，目标总仓位不超过95%，保留至少5%现金目标。基础与执行压力最大回撤预算30%；原投资准入20%线另列，研究通过不代表投资准入。
- 保留当时资格：上市观察、当时已公告规模、20日日均成交额、缺价和退市限制。次日开盘执行、整数份额、现金约束、2%ADV参与率、佣金、滑点与冲击均复用事件引擎。
- 513100从行情、资格、特征和信号中剔除，配置若包含该标的直接拒绝；逐笔成交验证均属于剩余30只。
- 完成条件：两个区间基础收益达标、至少2/3预登记邻域满足长期收益及30%回撤预算、6项执行压力正收益且回撤不超过30%；账本复核、因果性检查、冻结配置与独立重放一致。
- 数据限制：既有31只存续池的历史已经查看。此次研究仍属历史开发选择，不能将分段包装为新的盲测；完整历史目录、公司行动与真实前瞻准入缺口持续披露。

## 初始事实与假设

2026-09-13先查看了全池买入持有诊断：在有完整2016起点价格的非纳指标的中，黄金年化约13.69%，其余均明显低于标普；2021以来行业差异很大。上述数字未扣交易成本、未实施历史资格，不能当作可执行策略结果。具体行业的历史赢家不作为固定配置依据。

假设：黄金与国内权益的趋势相关性较低，预先规定的绝对/相对动量可在上行资产间轮动；不合格或缺少正信号时停泊合格国债或现金。通过长期与近期双区间以及完整邻域检验，区分持续机制和历史偶然收益。
