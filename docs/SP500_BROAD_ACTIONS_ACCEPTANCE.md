# 20项已知公司行动原件验收

日期：2026-09-14。本阶段完成13只ETF、20项已知事件的发行人原件核验，覆盖12次拆分/合并、8次分红。字段证据验收通过；发现旧行情复权因子存在偏差，行情序列和执行接入尚未通过，投资策略仍未达标。

“平均回撤”沿用常见的全交易日逐日平均回撤定义：以历史累计最高经济净值为基准，计算每个交易日的回撤深度，再取算术平均，新高日计零。它不是年度最大回撤的平均值。用户要求按业界通常定义评估，本项目据此明确采用上述口径，不表述为用户亲自选定了某个公式。收益仍比较十年CAGR，基准为同一中国交易日历上的人民币SPY含分红收益，项目20%最大回撤及126日真实前瞻门槛保留。

## 剩余缺口和投资结论

原件已覆盖本轮20项，并不表示这13只的所有历史事件均已完成原件核验。全池现有已知字段状态为：14只已知事件有原件、6只仍有部分日程仅有第三方资料、10只现有源未观察到区间内上市后行动。后者不代表已证明没有行动。

仅第三方支持的日程仍有31项，分布在上证50 510050（10项）、中证500 510500（4项）、红利510880（10项）、中证1000 512100（2项）、有色金属512400（3项）、计算机512720（2项）。因此不能把本轮13只全部提升为“全部已知日程原件齐全”。明细见`remaining_secondary_schedules.json`。完整30只存续、清盘及公司行动目录审计仍未完成。

本轮不持有相关标的的旧固定候选，已冻结回放结果保持年化16.23%、逐日平均回撤7.30%、最大回撤26.63%；基准人民币SPY分别为15.34%、3.42%、32.78%。候选平均回撤仍高于基准，最大回撤仍超过项目20%线。这里引用旧结果用于说明当前准入状态，没有对旧策略作新回测，也没有将这些历史试验改称样本外。

下一阶段先处理独立研究序列与执行扩展中的非整数取整、同日权益、支付确认问题，再补剩余已知日程原件，完成验收后登记新分散策略。用户账户、券商回报未提供，真实前瞻仍为0/126；模型成交不会填充真实前瞻。正式指针及现有每日自动化保持原状态，本阶段不产生实盘下单指令。整体目标仍在进行中，尚未达到投资准入要求。
