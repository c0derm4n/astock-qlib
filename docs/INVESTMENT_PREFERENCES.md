# 投资目标与用户偏好

更新日期：2026-10-13。来源：用户在本项目对话中的明确要求，后续研究证据另标日期。

## 联合目标

- 近十年CAGR ≥ 13.50%。
- 最差年度收益 ≥ −5%。
- 全期最大回撤 ≤ 40%。
- 最差年度按完整自然年收益理解，首尾不足一年另报；全期最大回撤按复利账户净值相对历史峰值的损失计算。滚动12月收益可补充披露，但不替换用户的年度指标。

## 决策优先级

- 用户风险偏好较低，最差年度收益和最大回撤的控制均优先于CAGR。
- 用户未规定两项风险指标之间谁更优先，不擅自添加排序。
- CAGR是三项中优先级最低的指标：允许将风险表现更好、CAGR不足的方案保留为首选候选，但必须明确联合目标尚未全部达到。
- 40%最大回撤是目标上限，不是要主动用满的风险预算。不要为了追求13.50%年化主动抬高风险。
