## 为什么不能采用

主方案2021、2022年分别亏损11.23%、8.02%，未避免连续亏损；2025年收益60.73%，也低于原固定配置现金候选约97.65%。三期限选择和等权方案2025年分别74.16%、56.00%。将资金转向相对强势资产的假设没有在本批规则下获得支持。

主方案基础回放的逐日双边换手率合计122.99，十年平均约每年12.30；三期限选择和等权约为每年14.25、13.05。计算为每日买卖成交额除以前日净值，再对日期求和，不是单边年度换手率。滑点加倍使三个方案年化进一步下降约0.71—0.82个百分点。

历史价格不足253条时不交易，主方案首次非零信号为2017-01-13，没有借用上市前或不存在的历史。全年和各年收益均留在JSON，不能删除这段现金等待或某些亏损年份改善展示。

## 发现的换手执行缺口

原执行器的`max_daily_turnover=0.3`先从预算中扣减目标卖出，再限制买入；它没有对卖出加同等硬约束。下单参考价与次日开盘价也有差别，因此实际双边成交额/前日净值可以高于30%。本批沿用冻结原执行行为，独立核对实际成交而不是只检查参数存在：

| 基础方法 | 超过30%的交易日 | 最高实际日双边换手 |
| --- | ---: | ---: |
| 趋势强度比例 | 61 | 87.30% |
| 三期限选择 | 199 | 86.22% |
| 正向趋势等权 | 203 | 94.41% |

9个情景都不能声称通过30%硬上限。这是额外的执行缺口，不改变本批策略已经失败的结论。后续应使用独立执行扩展限制全日买卖共享预算，验证跳空、清仓、整手和部分成交；不修改冻结引擎或回写已有结果来掩盖差异。
