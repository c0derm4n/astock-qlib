# 动态ETF账户策略：修订目标与首批探索

用户于2026-09-14明确要求动态选择ETF及调整仓位，并将验收目标改为：近十年CAGR不低于标普500的一半，年度最大回撤不高于标普500。本文件优先于旧研究中的收益与日均回撤门槛。

- 固定30只候选池，每日收盘运行；目标持仓由当日及以前的信号、资格和账户决定，可买入、加仓、减仓、清仓或不操作。固定通信/黄金组合仅作历史对照。
- 共同区间2016-09-12至2026-09-11。人民币SPY含分红基准；年度最大回撤逐年比较，以去年末净值为起点重置年内高点。首尾不完整年度也按共同片段比较。不是比较年度回撤均值，也不是把基准全年结果用于当年交易。
- 两项历史验收：CAGR≥0.5×同期基准CAGR；每个共同年份的最大回撤≤同年基准。原日均回撤和20%全期回撤继续披露，取消作为本轮用户指定的历史表现硬门槛。真实账户、数据完整性及前瞻证据属于另行实盘准入条件。
- 先复核已验收的分组与资金重新分配动态方案，不将旧固定方案当作最终方案。
- 首批经济假设：月内目标退出后等到下月才重选可能导致闲置和错过恢复趋势；将同一分组风险均衡策略的重选频率改为每周，保持月度对照和每日邻域，检验响应速度与成本的权衡。
- 所有方案每日检查退出与权重；只改变重选时点。保留63/126/252动量、253个连续真实价格要求、行业去重、4个槽位、风险均衡、15%理想目标预测波动及原执行规则。每周按周一所在自然周的第一个观察交易日重选。
- 预登记月/周/日三种频率×基础/滑点2倍/分红延迟5交易日，共9个十年情景。每周是主假设，不按结果换主方案。全部落盘，独立核验每日账本、共同基准与逐年指标；登记不产生新的样本外证据。
