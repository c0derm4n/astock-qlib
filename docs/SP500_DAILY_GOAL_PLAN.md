# 30只ETF每日策略：目标核验与落地计划

日期：2026-09-13。用户目标：每天检查一次，仅买入指定30只ETF，满足规则时触发调仓并指导人工操作；近十年平均回撤不高于标普500，同时年化收益达到标普500水平。

## 本轮事实与验收口径

- 上一轮可视化修复已完成，属于进展。本轮以工作区文件重新核验策略目标，不沿用 `historical_goal_verified` 作为整体目标完成证据。
- 旧30只池研究仅验证累计收益、CAGR与30%最大回撤预算；未计算平均回撤。旧收益容忍度为落后2个百分点，不等同于严格达到基准。
- 同币种主基准使用冻结的SPY含分红人民币序列；策略扣费。日均回撤与逐年最大回撤均值同时报告，回撤用正的损失幅度，越小越好。
- 近十年为基准截止日向前10个公历年后的首个共同交易日。既有净值切片仅用于持有状态延续诊断；另对冻结主候选从该日现金重新建仓，不把两者混用。
- 年度最大回撤均值仅包含区间内中间的完整自然年，每年以前一年最后净值作为起点并重置高水位；并列全区间最大回撤。
- 严格对标检查CAGR不低于人民币SPY，分别报告日均回撤与年度最大回撤均值是否不高于SPY。平均回撤口径已向用户询问，尚未回复；不擅自将同时满足两项设为用户新要求，也不将仅一项通过写成无条件达标。旧研究容忍标准单独显示。
- 历史选择偏差、2025年依赖、历史数据审计与真实前瞻不足仍须披露；新代码与结果独立存放，不覆盖旧冻结规则或验收。
