# 30只ETF趋势与波动风险方案验收

日期：2026-09-13。结论：预先登记的6个风险方案、18个情景全部完成并通过归档复核，但**没有一个同时达到收益和平均回撤目标**。不将低回撤但收益不足的方案替换为最终策略，原投资准入仍未通过。

## 同区间、同基准的基础结果

2016-09-12—2026-09-11，共2428个中国交易日，从模拟100万元现金建仓。策略含交易成本；基准为含分红再投资、折算人民币的SPY。回撤以损失幅度表示，越低越好；年度均值使用2017—2025完整自然年，每年纳入前一年最后净值作为起点。

| 方案 | 年化收益 | 年度最大回撤均值 | 日均回撤 | 全期最大回撤 |
| --- | ---: | ---: | ---: | ---: |
| 原现金候选（既有对照） | 15.97% | 13.23% | 7.48% | 26.75% |
| 120日趋势 | 12.09% | 9.79% | 6.28% | 25.14% |
| 200日趋势 | 12.23% | 9.63% | 6.81% | 26.45% |
| 240日趋势 | 12.31% | 9.79% | 7.29% | 26.63% |
| 20%波动预算 | 13.56% | 12.90% | 7.12% | 24.00% |
| **200日趋势＋20%波动预算（预登记主方案）** | **10.75%** | **9.25%** | **6.26%** | **16.91%** |

| 人民币SPY含分红 | 15.34% | 13.55% | 3.42% | 32.78% |

主方案将最大回撤降至项目20%门槛以内，但年化落后基准4.59个百分点。其平均投资仓位55.56%，2025年收益65.33%，低于原候选97.65%；减少暴露的同时也放弃了部分上涨收益。2022年损失从原候选约17.15%降至约3.40%，说明这组规则在持续下跌中有保护作用，但未满足整个十年的联合目标。

单独趋势退出的120、200、240日邻近窗口给出了相似结论：年度平均回撤下降，年化只有约12%，且仍未通过20%全期最大回撤门槛。此处没有出现支持“只要换一个附近均线参数就能达标”的证据。
