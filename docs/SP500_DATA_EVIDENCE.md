已完成三个预登记现金分红情景，从100万元现金按登记日权益、除息日应收、支付日现金和真实拆分份额重建十年。基础年化15.97%，年度最大回撤均值13.23%，日均回撤7.48%；收到分红64,490元，归档独立账本最大误差小于0.000001元。收益和年度平均回撤继续达标，日均回撤未达标。见[现金分红阶段验收](SP500_CASH_REPLAY_ACCEPTANCE.md)。
