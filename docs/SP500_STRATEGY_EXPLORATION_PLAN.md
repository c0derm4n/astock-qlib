# 31只ETF对标标普500策略探索计划

目标：在项目固定31只ETF范围内，探索可执行、扣除交易摩擦后累计收益与年化收益接近同区间标普500的策略。此前v2.1.1作为对照，现有投资准入要求继续单独报告。

## 比较与验证口径（2026-09-13建立）

- 主比较区间先固定2021-01-04至最新共同可验证交易日；补充2016年以来可用历史和分年度/分市场环境结果，不以挑选起止日提高结果。
- 基准采用标普500价格指数及分红再投资代理SPY，并区分美元与人民币口径。人民币策略优先与美元全收益按同期USD/CNY折算后的基准比较，美元原口径并列报告。基准数据需有来源、时间戳与原始快照。
- “接近”的初始研究判定：年化差距不超过2个百分点，累计收益至少达到基准的85%；同时报告精确差距，不仅给出通过标签。最终结论须注明基准口径和风险差异。
- 不加杠杆、不做空；仅从31只ETF选择，上市观察期、当时可见规模、流动性与可交易价约束保留。两只QDII纳入独立研究分支，使用场内实际价格，不拿境外指数替代成交价格，明确溢价与不同市场时区问题。
- 收盘信号、下一交易日开盘执行；佣金、滑点、冲击、整数份额、资金约束和部分成交纳入。本轮按与标普可比较的风险量级研究，回撤同时对比原20%门槛与标普实际回撤。
- 已使用的2021–2026历史只能支持开发研究；完整试验登记，失败结果保留。任何历史目标达成均不自动意味着投资准入通过。
