## 2. 组合与执行改进

1. 并列排名采用同一最优名次；新建仓时，边界并列组超过剩余TopK名额则整组留现金，避免用ETF代码决定赢家。
2. 部分卖出后持续记录退出意图，退出中的标的不因排名回升而重新买回；处理复权单位零股尾仓，避免永久无法清仓。
3. 买单只使用已有现金与实际持仓的单只、分组、权益及总仓位余量，不预支尚未完成的卖单。回测执行时按真实开盘价再次核对预算，决策端共享同一约束逻辑。
4. 固定20%十年国债ETF、10%黄金ETF底仓，65%为最多6只权益ETF轮动目标；底仓缺资格时留现金。持有期20交易日、排名缓冲2名，波动及集中度约束仍适用，实际仓位可能低于目标。
5. 保存6个压力情景的净值与逐笔成交，新增去底仓、去排名缓冲两个消融，并把行情覆盖纳入准入门禁。

基准研究资本100万元；单只上限20%、分组35%、权益70%、总仓位95%，目标波动15%，日换手预算20%，成交额参与率上限2%。佣金0.03%、单笔最低0.2元，基础滑点0.05%，另计冲击成本。信号在正式日线完成后形成，次日开盘执行。完整规则见 [冻结协议](../output/runs/20260912-220345-f20ea3f5/protocol.json)。
