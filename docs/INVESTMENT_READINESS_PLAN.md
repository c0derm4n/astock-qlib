# v2.1.1 投资准入改进计划

本轮继续使用 backtest-expert 方法。2021–2026 历史已参与设计，本次结果属于开发研究，不是新的独立样本外证据。20%回撤、成本压力、统计置信、完整历史审计和126真实观察日要求全部保留。

## 已观察到的问题

- v2 LightGBM在1347天中有581天的不同打分少于6档，并列边界不能用代码排序制造优势。
- 主模型日均双边换手6.16%，2100笔成交，手续费约2.28万元、滑点及冲击约4.03万元。
- 部分卖出后，未清完的标的会重新进入排名集合；剩余退出意图丢失，加剧路径依赖。
- 生成买单不应假设卖单全部成功；必须按现有现金与风险余量约束，执行时按真实开盘价再检查。

## 冻结的新假设与实施

假设：稳定的债券/黄金底仓配合低复杂度相对收益排序、排名缓冲与持续退出，能减少无效换仓及部分成交引起的风险失控，同时保留轮动机会。

1. 修复并列边界、部分退出意图与现金/风险约束；增加反例测试。
2. 新研究主模型为Ridge，保留momentum与LightGBM对照。主模型变更是开发假设，不自动批准旧历史赢家。
3. 固定债券20%、黄金10%底仓；剩余65%为最多6只权益ETF的轮动目标；风险上限仍适用，缺资格的底仓保留现金。
4. 排名缓冲2名、持有20交易日，邻域Top4/6/8与持有10/20/30天。不根据本轮结果继续选最优点。
5. 所有模型使用一致组合规则，保留股债金/等权/沪深300ETF参考。成本、容量、部分成交、延迟全量重跑，并增加底仓与缓冲消融。
6. 完整回归、生产模型/模拟账本、Web/API指标对齐验收；逐项报告投资准入状态。
