# 权益与黄金动态配置研究计划

日期：2026-09-13。上一目标轮完成早期原件补证和回撤归因，分类为进展。原候选三段长期回撤贡献了日均回撤的78.3%，固定权益暴露是主要来源；18个仅缩仓的风险情景均未达到收益目标。因此本阶段改变资本在资产之间的配置机制，检验转向相对强势资产能否改善收益和长期回撤的组合结果。

## 预先固定的研究范围

仍只买入固定30只ETF允许范围内的通信515880、黄金518880及沪深300 510300，三者参与动态分配。此前选择这三只本身有历史选择偏差，本研究不会消除这一点。沪深300这次作为同等候选参与，不再只在通信资格不足时替代。

3、6、12个月分别使用63、126、252个交易日，要求包括当天在内253条连续有效价格；不足则现金等待，不补造上市前历史。每个期限以年化对数动量除以63日年化波动率得到风险调整动量，波动率下限5%。不拟合收益、分类标签或行业权重。

- 主方案`proportional_strength`：三个期限得分取平均，在均值为正的资产中按得分比例分配95%预算。
- 对照`horizon_votes`：三个期限各使用三分之一预算，选择该期限正得分最高的资产；并列等分，无正得分则该份额现金。
- 对照`equal_positive`：三个期限平均得分为正的资产等分95%预算。

单只上限85%，原分组、权益、总仓位、换手、整手、交易额参与率、漂移带、费用和保守现金预算保留，受限预算不再强制投入其他资产。每天收盘一次，次日开盘执行；没有正信号则留现金，现金利息按0。

## 目标保持

严格十年2016-09-12—2026-09-11，现金100万元重新建仓；基准为人民币SPY含分红、同一中国交易日。CAGR须不低于基准，逐日平均回撤须不高于基准；年度最大回撤均值补充报告，原20%最大回撤准入线单独保留。逐日均值包含创新高日的0回撤，不换成回撤事件均值或年度均值来达标。

全部历史已被研究，本批属于机制探索，登记时间不能把已知历史变成独立样本外。即使历史联合目标通过，公司行动/完整30只历史目录、真实账户和126日真实前瞻等未完成时，整体目标仍未完成。每日入口与现金模型的应收分红衔接也须在合格候选确定后处理。

新代码位于`research/goal30/relative_allocation.py`，结果位于`output/goal30/relative_allocation/`；不自动切换正式/每日策略，不自动下单，不重复创建自动化。
