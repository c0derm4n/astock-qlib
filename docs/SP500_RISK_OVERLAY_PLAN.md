# 30只ETF风险控制方案研究计划

2026-09-13。继续原始目标：每天检查固定30只ETF，在适当条件下调仓；严格近十年年化不低于人民币标普500，平均回撤不高于基准，并保留既有投资准入要求。

上一阶段上市日期证据完成，属于实质进展。本阶段研究当前候选的风险差距，不改行业、不重选权重、不放宽收益或回撤门槛。

## 已知问题与假设

当前候选为60%通信、35%黄金和5%现金目标。基础现金回放年化15.97%，年度最大回撤均值13.23%，日均回撤7.48%，最大回撤26.75%。最大回撤从2026-06-22延续至2026-07-30；固定策略当前为`observe_only`，没有波动缩仓。

假设：长期趋势走弱时退出该资产，配合仅使用过去收益估计的波动预算，能减少持续下跌中的暴露，并保留上升趋势的收益。缺点是可能遭遇反复买卖、卖出后踏空，以及快速反转时保护滞后；这些均须由完整结果检验。

全区间以及此前95个候选的历史都已看过。本次是后续探索，登记时间不会使已有历史变成独立样本外数据。

## 预先固定的实验

主方案：200日趋势门槛加20%年化波动预算。比较120/200/240日单独趋势退出、单独20%波动预算，以及200日趋势加15%波动预算，共6个方案。

每个方案运行基础、滑点加倍、分红支付延迟5日三个情景，共18个。原现金基础回放作为现有对照，不因新增研究重新计算相同十年结果。

详细规则在`research/goal30/risk_overlay_protocol.json`。趋势以当日收盘复权价与过去N日简单均价比较，严格高于才持有；缺数据、等于均价或趋势不满足则留现金。每日收盘信号在下一交易日开盘执行。

市场资格不足才触发原沪深300代理；趋势退出不触发代理。代理也接受自身趋势检查。波动预算采用已有60日协方差与252日年化方法，保留原集中度、漂移带、成交额参与率、整手、现金和公司行动规则。
