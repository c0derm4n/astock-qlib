# 本地正式策略服务 v3.4.0

在项目根目录运行 `.\start_local.ps1`，或双击 `start_local.bat`，浏览器打开 `http://127.0.0.1:8000`。启动脚本构建前端，并在登记或数据过期时重建快照。已有构建可用 `-SkipBuild`；强制更新用 `-Refresh`；端口冲突可用 `-Port 8001`。

## 三项模型与各自执行口径

稳健、平衡策略每周首个中国交易日收盘评估，下一交易日开盘模拟执行，触发才调仓。佣金、最低佣金、滑点、容量、现金和整手约束沿用各自协议。通信只有失去市场资格才允许沪深300替代；跌破趋势线持现金。

PE采用ETF.run公开声明的等权PE，保持下一交易日19:00可得的历史重建假设；不是整体法估值或PIT快照。估值过期会暂停新建议。账户试算需要批次和冷却历史，因此PE不接受仅输入现金/份额的普通试算；通信/黄金继续支持与所见快照绑定的账户试算。

积极策略A用H20269全收益与H30269价格指数反推252交易日派息率，按5.0/4.8/4.2/4.0/3.8/3.6%阈值配置95/85/70/60/50/35/20%红利；国债目标为95%减红利目标，511260上市前留现金。A为周首收盘信号、T+1收盘模拟执行，时效窗口按15:00判断；另两项仍用T+1开盘。5个百分点漂移带、单边max(5元,成交额×0.10%)、红利0.60%年化复制费沿用研究A；不加入均线熔断、黄金或其他变体。

A数据种子位于 data/formal/dividend_band/seed/，预热从2014年开始。新增官方指数数据核对身份、重叠历史、交易日完整性和原始响应哈希；国债用正式数据库原价×复权因子续接。2018-08-17只使用已核查净值估值、不成交。模型生成动态仓位、周度信号、历史等值成交和资金曲线，不能把等值数量当成ETF整数份额；普通真实账户试算禁用，并展示具体原因。隐含股息率不是官方股息率，历史快照非PIT，基础情景胜出不代表时点和成本压力全部胜出。

各项仍保留年化≥13.50%、最差完整年≥−5%、最大回撤≤40%的目标。正式服务登记与分类不等于三项目标达标或实盘准入。

## 快照、数据与接口

- `output/strategies/current.json` 指向一个完成并验收的不可变运行；所有接口绑定同一 `run_id`。重建失败不覆盖已有有效运行。
- 三项全部构建后才原子切换指针。当前运行不生成 `annual_model.pkl`、`predictions_lightgbm.pkl` 或模型年度折。
- `GET /api/strategies`、`GET /api/development/overview` 只按上述顺序返回三项。顶层 `risk_label` 和 `display_priority` 与登记一致。
- `GET /api/development/universe`：PE返回一只ETF，通信/黄金返回三只；A返回红利/国债两项等值参考，tradeable=false。
- `GET /api/development/picks`：PE返回估值线，通信/黄金返回趋势与资格；A返回 kind=dividend_band、所选历史周首的隐含股息率、目标配置、仓位和等值金额。
- `GET /api/development/backtest`：各自每日资金曲线、年度指标与口径；A成交不伪造ETF数量/价格，周度持仓展示金额和权重。
- `POST /api/strategies/{id}/preview`：仅通信/黄金支持。PE与A返回400并说明原因；停用ID返回404。
- `POST /api/strategies/refresh` 与 `GET /api/strategies/refresh/status` 提供手动刷新，不安装自动调度、不连接券商。写请求要求 `X-Local-Request: 1` 和本地来源；仅监听127.0.0.1。

行情截止按上海时间19:00判断完整交易日。行情/估值缺口明确展示过期状态，不将失败转换成新建议。行情库可保留已有其他ETF的历史数据供旧研究审计，这不表示停用策略仍参与加载或计算。

手动构建：`.venv\Scripts\python.exe -m src.formal_service --fetch`。不抓行情时去掉 `--fetch`，所有输入仍须覆盖共同截止日。

A首次部署的数据种子可用 python -m src.formal_dividend --initialize-seed 从已核验研究数据建立，并向当前正式共同截止日追加官方行情；已有种子禁止覆盖。此步骤不更改研究目录或原研究回放。
