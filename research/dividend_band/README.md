## 信号定义

- 红利：H20269 官方全收益日收盘（2014—2016 预热来自中证官方接口按年原始响应）；持有方按日历天扣 0.60% 年化复制费情景。
- 价格：H30269 官方价格指数日收盘（不含股息）。
- 隐含派息 `D_t = TR_t/TR_(t-1)*PR_(t-1) - PR_t`；滚动 252 个交易日派息总额 / 当日价格 = 隐含股息率（2026-11-04 为 4.97%，中证官网同期披露 4.65%，量级一致但口径不同）。
- ERP = 隐含股息率 − 10 年期中国国债到期收益率（东方财富原始分页 JSON 留档，按 XSHG 交易日向前填充）。
- 百分位：滚动 756 个交易日、最少 252 个观测的窗口内百分位，含当日、只用过去。
- 国债：511260 收盘×复权因子；2017-08-24 上市前保留现金；2018-08-17 缺报价只估值不成交。
- 深度破位保护：`PR < MA250×0.96 且 MA250 < 20日前` 或 `vol60 > 20%` 时红利目标压到 30%。

## 档位与执行

| 表 | 阈值 → 目标红利权重 |
| --- | --- |
| abs_dividend（A） | ≥5.0→95%，≥4.8→85%，≥4.2→70%，≥4.0→60%，≥3.8→50%，≥3.6→35%，其余→20% |
| abs_dividend_wide（B） | ≥4.8→95%，≥4.0→70%，其余→40% |
| pct_dividend（C） | ≥80→95%，≥60→80%，≥40→65%，≥20→50%，其余→30% |
| abs_erp（E） | ≥3.0→95%，≥2.8→85%，≥2.2→70%，≥1.8→55%，≥1.4→40%，其余→25% |
| pct_erp（D） | 与 pct_dividend 同结构，指标换成 ERP 百分位 |

- 每周首个中国交易日收盘评估，T+1 收盘执行；红利与国债目标合计 ≤95%，闲置部分为现金。
- 非零目标与现有权重差 <5 个百分点时保留原权重；目标为零不受漂移带约束。
- 每方向 `max(5元, 成交额×0.10%)`；国债价格已含基金费，不重复扣；现金零息。
- 登记目标先按 95% 封顶，再应用漂移带；成交费造成的千分之一级超配不再被强行拉回，避免每周支付最低佣金。

## 局限

- 隐含股息率是从全收益与价格指数反推的近似值，含价格漂移影响，不是中证官方股息率口径；官网免费接口只给滚动 20 个交易日。
- 全部历史已被查看，没有真正未见数据的盲测；档位阈值来自用户给定的方案三表述，但仍属事后研究。
- 分数等值份额、指数代理账户；未验证 100 份整手、真实券商收盘成交、成交容量与全量停牌/涨跌停约束。
- 2017-08-24 前国债 ETF 未上市，该段闲置资金为现金；2016—2017 年的国债承接增益不成立。
- 用户联合目标（年化≥13.5%、最差年≥−5%、回撤≤40%）中，A／B／E／D 满足两项风险目标但年化都差 4 个百分点以上；C 年化最高却已跌破年度亏损线，只满足回撤一项。没有任何候选三项同时达标，不据此切换正式策略。
