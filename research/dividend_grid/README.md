## 固定规则

- 每周首交易日收盘评估，T+1收盘执行；只有过去数据，无黄金、无美股、无杠杆。
- H20269全收益相对MA200乖离≤-5%／-10%，逐周从60%升到75%／95%；每周最多一档，保持目标状态至下次触发。
- 乖离≥6%时95%降到75%，≥8%时75%降到60%；卖出波段仓，不因过热清空核心仓。
- `(P<MA250×0.96且MA250较20日前下降)或vol60>20%`触发风险状态，优先限制红利总目标为30%，清除波段状态。
- `P>MA250×1.01、斜率非负、vol60<18%`连续两周恢复至60%，恢复当周不加仓。
- 国债目标`95%-红利目标`，剩余现金零息；511260于2017-08-24上市前保留现金，不造上市前收益。
- 非零目标3个百分点漂移带，风险缩仓绕过漂移带；每方向`max(5元,成交额×0.10%)`。
- 指数代理红利持有扣0.60%年化复制费用情景；2019起ETF模拟用原价、100份整手、实际场内分红应收和到账，基金费不重复扣。
- ETF成交额不超过前20个有效报价日平均额及当日实际成交额各5%；部分成交等下周重算，缺报价延后。目标上限不是即时成交保证。
