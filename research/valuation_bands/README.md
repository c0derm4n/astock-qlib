## 1. 目标、边界与完成定义

目标是把网络截图中的两套策略变为规则确定、因果可计算、账户可复核的周频研究实现：

- `A_pe_weekly`：沪深300历史低点PE中位数确定买入区间，分批买入沪深300ETF，估值修复后清仓。
- `B_pb_weekly`：创业板历史低点PB中位数确定买入区间，分批买入创业板ETF，估值修复后清仓。
- 分别实现三个已定义的对照模块：A的固定PE清仓、A的股债比较门槛、B的空仓期红利低波配置。辅助模块缺少合格数据时只阻塞该模块，不阻塞两个主策略的代码与现金版本验证。

本研究不把两套账户合成一个账户，不叠加到现有通信/黄金策略，也不选择生产赢家。实施范围为本目录、`data/valuation_bands/`、`output/valuation_bands/`；可以只读复用现有源码、行情和公司行动证据。若需修改共享引擎，优先在本目录封装局部适配，不改现有生产行为。

不得修改 `universe.py`、`strategy_registry.json`、`research_protocol.json`、`strategy_corporate_actions.json`、`output/strategies/current.json`、`output/current_run.json`、正式数据库或其他已冻结实验。研究扩展数据独立保存，不回写旧库。不得部署、安装调度、连接券商下单或自行购买数据。

投资目标沿用[投资偏好](../../docs/INVESTMENT_PREFERENCES.md)：近十年CAGR≥13.50%、最差完整自然年收益≥−5%、每日净值最大回撤≤40%；两项风险指标均优先于CAGR，不能擅自规定两项风险指标之间的优先级。仓位上限不等于风险目标保证，40%回撤上限也不是应主动用满的预算。

实施完成须同时满足：规则和输入已冻结、两条主策略通过针对性测试、历史运行或真实数据阻塞有明确产物、账户能独立对账、结果披露完整。代码完成、单次回测盈利和辅助模块跳过均不等于投资准入通过。

### 3.2 日期、时间与触发

- 时区统一`Asia/Shanghai`。每个自然周`W-SUN`中的首个中国交易日19:00评估；周一休市则顺延至本周首个交易日；整周休市则无信号。
- 信号只能使用当时可得信息；最早在下一中国交易日开盘模拟执行。收盘估值不能按同日收盘成交。
- 每周仅评估一次；其他交易日只记账、处理公司行动和更新每日净值，不重新判定买卖。未成交退出于下一周信号重发，不自动增加日频重试。
- 历史账户起点固定为`2016-09-12`，起始当日先保留100万元现金并在收盘评估；预热数据不得产生账户收益或起点前持仓。
- 首批研究请求终点为`2026-11-06`。登记时根据合格输入明确冻结`actual_end`；不足请求终点要披露缺口，不得填平末尾行情。不同策略对比采用共同有效区间。
- 起点前必须具有2011—2015五个完整自然年的指数价格和估值校准数据。缺少预热不能默认改用全样本分位，也不能静默后移起点。
- “触发才调仓”：仅分批买入、持续清仓、资格退出、每周风险限额修正或第7节资产切换产生订单。无触发时不机械恢复目标权重。

## 4. 历史低点与清仓阈值的因果定义

### 4.1 年度校准

对信号所在年份`y`，只使用`y−5,…,y−1`五个完整自然年。每年首次有效周度评估时生成该年的校准快照，此后全年固定；年内不重算分位、不因结果调整阈值。已经取得的校准快照不被后续数据修订覆盖。

对每个历史年份`k`：

```text
d_k = 当年价格指数日收盘点位最低的交易日；并列时取最早日期
v_k = 同一指数在d_k的PE_TTM（A）或PB_MRQ（B）
M_y = median(v_(y-5), ..., v_(y-1))
H_y = 上述五个完整年份中合格的每日估值观测集合
L1_y = 1.10 * M_y
L2_y = 1.00 * M_y
L3_y = 0.90 * M_y
S_y  = quantile(H_y, q, method="linear")
```

`quantile`固定为线性插值，即常见Type 7定义。`M_y`是五个年度价格低点当天估值的中位数，不是五个年度最低PE/PB的中位数，不是历史估值20%分位，也不是全样本中位数。

年度最低价格可以在该年度结束后确定，所以用于下一年度属于因果规则；它仍是对截图未知“几个历史低点”的工程替代，不能声称恢复了作者选点。指数价格必须与估值对应同一指数；不得用ETF除息后的最低价代替指数低点。

### 4.2 合格条件与年界行为

- 每个校准年度的指数价格须覆盖全部中国交易日，以免遗漏真正最低日；估值至少覆盖95%的交易日。五个最低点当天必须同时有精确日期的价格和有效估值，不为低点日估值插值。
- `H_y`只计非重复、有限且大于0的有效日观测，五年合计至少1000条。不得先前向填充，再把重复估值计作新样本。
- 使用的原始/重建财务与成分口径、历史发布可得性必须满足第8节；不能只因日期早于信号，就把事后重述值认定为当时可得。
- 必须满足`0 < L3_y < L2_y < L1_y < S_y`。失败时该case记录`invalid_threshold_order`并停止产生新策略结论；不自动调高清仓线、压低买入线或另选分位“修好”。
- 新年校准成功后，对所有持仓使用新年的阈值；成功买入批次和买入间隔不因跨年归零。阈值变化导致的退出是有效信号，需单列`annual_recalibration_exit`原因。
- 校准数据不足则该case记录`calibration_data_blocked`，保留日志和已生成账本；未完成case不能作为完整历史结果参与排名。

### 4.3 估值线映射到指数点位

图表可以展示`价格指数点位 × 估值阈值 / 当前同口径估值`，但这只是画图映射，不是交易价格。即使阈值固定，盈利/净资产变化也会使点位线移动。不得将价格指数PE阈值直接套到全收益指数点位上，或据此计算真实ETF成交。

## 5. 两条主策略共用的交易状态机

### 5.1 状态与估值档位

每个账户独立保存：`phase`（`flat/holding/exiting`）、`buy_steps`（本轮成功买入批次，0…3）、`last_buy_execution_session`、实际ETF份额、现金、分红应收以及未完成退出意图。状态必须由事件日志恢复，不能只存一个“理论仓位”。

```text
若 V_t <= L3_y：allowed_steps = 3
否则若 V_t <= L2_y：allowed_steps = 2
否则若 V_t <= L1_y：allowed_steps = 1
否则：allowed_steps = 0
```

周度处理优先级固定为：**已有退出意图 → 资格退出 → 高估清仓 → 数据有效性检查 → 风险限额修正 → 低估分批买入 → 持有不动。** 数据缺失不能取消已有退出意图；估值缺失本身不制造新的“高估卖出”。

### 5.2 买入

同时满足以下条件，才允许申请一批买入：

1. 不处于`exiting`；信号估值有效且新鲜，交易ETF具备当时资格。
2. `buy_steps < allowed_steps`，且`buy_steps < 3`。
3. 尚未买过，或距上次成功买入执行日已满20个中国交易日；本次信号日的交易日序号减上次执行日序号至少为20。
4. A主策略没有额外门槛；`A_pe_ratio_gate`须额外满足第6节。
5. 没有优先级更高的卖单，现金和风险上限允许增加仓位。

```text
next_step = buy_steps + 1
target_weight = w_cap * next_step / 3
buy_value = max(0, target_weight * NAV_signal - current_ETF_value_signal)
```

每次信号最多申请一批；即使第一次遇到最深档，也只能先买第一批，不能一天买满三批。只因估值仍在第一档，不会每月无限加仓；第二、三批还必须进入相应更低估值档位。

按信号日真实收盘价把目标换成100份整数买单，扣除费用预留，并在执行时再受现金和上限约束。买入订单只在指定执行日尝试一次：

- 实际买入份额>0，才令`buy_steps += 1`，并记录执行日；部分成交也算本轮一批，剩余买量取消，不每日追单。以后符合更低档与间隔时，可申请下一批。
- 0成交不增加批次、不启动冷却；后续周度条件仍满足时可重新申请同一批。
- 四舍五入后不足100份、已有持仓市值已不低于本批目标或资金不足，不下买单，也不增加批次。
- `buy_steps`是分批事件计数，不是实际仓位；不得用它代替成交份额、现金或持仓市值。部分成交和风险减仓后，实际仓位可以低于理论目标。

### 5.3 持有、退出与重新入场

- `L1_y < V_t < S_y`时继续持有；价格反弹离开买入区间不单独减仓。
- 低估程度变浅，不回退成功批次，不重复补齐旧批次；本方案没有固定持仓20个月的到期卖出。
- 当前有效且新鲜的`V_t >= S_y`且实际持仓>0时，锁定整只ETF的`exiting`意图，下一交易日开盘申请清仓；不是把85%或75%当作卖出仓位比例。实际已空仓时保持`flat`，不创建虚假的退出意图或退出事件，B的红利模块仍可按第7节判断。
- 清仓失败或部分成交后，意图继续有效，下次周度评估继续卖出；期间即使估值重新低于买入线，也不撤销退出、不买回。
- 只有实际份额为0，才结束本轮、把`buy_steps`和上次买入日期归零。若下一次周度信号重新满足买入条件，可以新开一轮，不要求价格先从买入线上方再次下穿。
- ETF市场资格失效同样锁定退出；因价格缺失无法成交时，不虚构成交。

### 5.4 风险上限与无效数据

目标权益不超过A的60%或B的40%，可用现金目标至少5%；不得以分红应收支付买单。每周评估时，若实际权益权重超过上限3个百分点，则申请减回上限；若流动性现金不足净值5%，申请适量卖出补足。两者均不得顺带加仓。

上限是决策与买入时的约束，不保证交易间隔内因价格漂移、停牌或部分成交而始终满足。报告应披露实际最大权益权重和超限持续天数。风险修正不清零`buy_steps`，也不在下一周机械买回；只有更深档、冷却及其他买入条件仍满足时才能再申请下一批。

当前估值缺失、非正、无穷或距信号日超过1个中国交易日时，不新增低估买入；保留持仓，仍执行已有退出、资格退出及风险修正。必须记录跳过原因与次数。持仓估价只允许已知最后收盘价最多沿用5个交易日；超过即停止该case并标记`unpriceable_holding`，不能让净值曲线静默延伸。

仓位上限没有提供年度亏损保证。本方案没有“达到−5%就能无滑点止损”的假设；风险未过线就报告未过线。

## 6. A的两个辅助对照

### 6.1 固定PE对照`A_pe_fixed14_34`

除清仓线改为固定`S=14.34`外，与A主策略完全相同。年度买入阈值仍按第4节生成；依然要求阈值严格有序。该case只能说明本项目账户下固定14.34的表现，不能视为复现作者结果。85%分位对应的PE通常会随校准年份变化，禁止把它强制锚定为14.34。

正文“14附近分批卖出”不再另外实现为第五种退出方式，避免无依据增加参数。

### 6.2 股债比较`A_pe_ratio_gate`

信号序列固定为沪深300全收益指数`H00300`与Wind混合债券型二级基金指数`885007.WI`。它们均只是信号/对照序列，不能按指数点位假装买到基金。

基日固定为`2015-01-05`，必须有两条真实观测，不自动改到回测起点：

```text
X_t = (TR300_t / TR300_base) / (BOND_t / BOND_base)
gate_t = X_t <= 1.00
最终买入许可 = 低估分批条件 AND gate_t
```

这是“归一化股票累计回报不高于二级债基时才加仓”的新增可执行解释。它采用区间门槛，不要求当周刚刚下穿；也不是比值历史低分位规则。只能限制新增买入，不触发卖出。退出条件与主策略相同，空仓仍持现金。

基日、归一化方式会影响信号；本研究固定后不根据结果移动交叉点。两条信号都必须在评估时可得且各距信号日不超过1个交易日，否则本周禁止新增买入。缺少`885007.WI`合法可用历史时，记录`blocked_optional_data`；不得自动用纯债指数、十年国债ETF、非纯债基金指数或债基现任净值替代。A现金主策略继续执行。

## 7. B的红利低波模块`B_pb_dividend`

### 7.1 研究标的与启用边界

候选固定为中证红利低波动指数`H30269`对应的`SH512890`。它是本方案对截图泛称“红利低波”的具体化，不是已确认的原作者标的。使用`H30269`指数股息率，不使用ETF最近一次分红率、当前成分股简单平均股息率或普通红利ETF代替。

`SH512890`不在当前生产30只ETF池中。后续实施先完成B现金版本；红利模块通过独立研究白名单和数据登记启用，不能修改全局池或放宽生产准入。后续开发授权若不包含新增研究标的，则该case记录`blocked_scope`，其余工作继续。本文本身不执行该扩展。

必须取得产品身份、上市日、历史原价、公司行动、当时资格及股息率口径证据。ETF上市且满足资格前，该模块持现金，不把指数上市前回溯收益接成可交易ETF收益。不能为了填满十年把`SH510880`当作同一产品。

### 7.2 股息率口径

`dividend_yield_ttm`存储为小数，例如5%存为`0.05`。必须采用同一来源、同一指数整体聚合口径的过去12个月现金股息率，记录税前/税后、权重/聚合方式及分红确认规则。来源只有静态股息率时，模块保持阻塞，不静默替换TTM。

优先采用指数提供方可核实序列，或采用可审计的当时成分/权重和已公开分红重建序列；只有商业数据供应商的历史序列时按第8节标记证据等级。当前股息率不能倒填历史。

### 7.3 交易与冲突优先级

- 创业板持仓或未完成的创业板清仓意图存在时，不新增红利低波。创业板空仓且当周满足创业板买入条件时，优先创业板。
- 创业板实际空仓、无创业板买入申请、两套信号数据有效，且`yield_ttm > 0.05`时，红利低波目标仓位30%；其余现金。允许一次申请该目标，仍受第9节普通买入预算和实际成交约束。30%为本方案新增的研究仓位，与普通单次买入预算一致。
- 已持红利低波且股息率仍>5%时持有，不每周恢复30%目标；若首次部分成交，不逐周补齐。权益超限/现金不足的风险修正仍有效。
- 股息率`<=0.05`时退出红利低波；等于5%不买，并清仓。这是本方案补齐的退出规则，截图没有给出。
- 创业板新买入申请产生时，先申请卖清红利低波，再在同一执行窗口按实际卖出所得资金尝试买创业板。只有红利低波实际份额归零，才允许执行这笔创业板条件买单；未卖清则该次买单取消，下个周度信号重算。
- 创业板清仓完成当日不临时新增红利低波信号；至少等下一次周度评估。不得同一笔资金同时按两种资产收益计账。
- 红利低波退出意图同样持续到实际清零。买入红利低波不改变创业板`buy_steps`；创业板实际清零后该计数已按第5节归零。
- 股息率或创业板估值缺失时禁止新增红利买入；已经持有红利则持有并标记数据失效，继续已有退出和风险修正。未知信号不等于“创业板没有机会”或“股息率仍>5%”。

两种权益目标合计不超过40%；正常完成切换后互斥。红利低波是权益资产，不能把这一模块称为无风险现金增强。

### 8.3 时点可得性

- `fetched_at`是本次下载时间，不能当作历史发布时点；也不能把今日下载的修订历史标为原始历史快照。

## 9. 执行模型、费用与真实现金账本

### 9.1 账户与订单

每天按真实ETF份额和不复权原价估值，分红按登记日确认资格、除息日记应收、支付日转可用现金；拆分只改变份额和相应价格基准，不创造收益。应收计入净值但不作为买入现金。使用复权价做辅助图或收益核对时，不能再重复加现金分红。

订单保存`signal_date/signal_timestamp/execution_date/side/reason/requested_quantity/filled_quantity/reference_price/adv20_snapshot/status`。正常信号只生成下一交易日一次执行窗口；缺少末尾执行日时保留`unexecuted_at_end`，不强制在期末收盘成交。

执行前先处理当日生效公司行动，后卖再买；买入只使用已到账现金和该执行窗口真实卖出所得。买量100份整数，卖清允许卖出持有尾数；不卖出未持有份额，不用尚未成交卖单所得提前买入。ETF适用的T+1卖出限制必须按产品规则建模，不能同日买卖同一新增份额。

普通买单合计金额最多为该信号日净值30%；清仓与风险修正卖单不受这一买入预算限制，但仍受成交量、停牌和实际可卖份额约束。执行价跳空后，买入再次按可用现金、至少5%现金及权益上限缩量；允许因此低于理论目标。

未成交买量在当次执行窗口结束后取消。未成交卖量通过`exiting`状态保留意图，在下周再申请；不是把原订单永久当作已成交。公司行动影响参考价或份额时，取消不再有效的在途订单并记录，后续周度重算，不能复用旧除息参考价。

### 9.2 基础费用和成交限制

| 参数 | 默认值与单位 |
| --- | --- |
| 佣金率 | 双边`0.0003` |
| 单笔最低佣金 | `0.20`元，沿用现有正式策略费率假设，非券商报价保证 |
| 基础滑点 | `0.0005` |
| 冲击系数 | `0.002` |
| 最大成交参与率 | 信号日前20日均成交额`ADV20`的`2%` |
| 冲击模型 | `impact = 0.002 * sqrt(filled_notional_at_raw_open / ADV20)` |
| 成交价 | 买入`raw_open*(1+slippage+impact)`，卖出`raw_open*(1-slippage-impact)` |
| 现金利息、ETF交易印花税假设 | 均按0；基金管理费已体现在产品价格/NAV，不重复扣除 |

默认值来自项目已有模拟口径。若产品适用的真实费用不同，应另登记数据和新情景，不能改写本批基础结果。

ADV必须来自信号时已知成交额；不可用次日全天成交量反推当时订单。缺少有效开盘价、停牌、零成交量或涨跌停无法可靠成交时记未成交；不得把估价前向填充结果当开盘价。

涨跌停和T+1规则要按ETF、历史日期及真实交易所规则处理；现有引擎对创业板ETF使用固定19.5%阈值仅是近似，不能不经核对就覆盖整个历史。优先取得历史实际涨跌停价；仅有OHLC且不能判断排队成交时，封板或疑似不可成交采用保守拒单并标记`execution_approximate`。

- `orders.csv`、`trades.csv`、`actions.csv`：申请、撤销、失败、部分成交、佣金、滑点及公司行动均可追溯。
- `daily_account.csv`、`holdings.csv`：每日现金、实际份额/原价市值、分红应收、净值、成本、累计换手与数据缺失标志。
- `annual_returns.csv`、`episodes.csv`、`metrics.json`、`case_status.json`：完整年/不足年、开平仓周期、未平仓周期和结果状态。

指标必须从含现金、费用、分红应收的每日账户净值计算：

```text
NAV_t = cash_t + sum(quantity_i,t * raw_close_i,t) + dividend_receivable_t
CAGR = (NAV_end / initial_capital) ** (365.2425 / 实际日历天数) - 1
DD_t = NAV_t / max(initial_capital, NAV_start, ..., NAV_t) - 1
最大回撤 = -min(DD_t)                  # 以正损失幅度披露
完整年收益 = 当年最后交易日NAV / 上年最后交易日NAV - 1
```

账户初始资金须纳入净值高水位，不能从首次成交后或第一年年末才开始算回撤。2016、2026在本次区间均为不足年，单列但不参与“最差完整年”；若实际数据进一步截断，也必须标明。

同时披露：累计收益、期末资金、完整年度收益与最差年、每日最大回撤及起止/恢复日期、滚动12月最差收益（补充）、实际平均/最大仓位、现金占比、各资产收益贡献、成交次数、闭合周期数、未闭合周期、平均闭合周期持有日数/月份、成本和缺失数据次数。

每轮交易以首次实际建仓至最后实际清零定义；未平仓周期单列，不当作已成功获利周期。红利模块的独立收益及切换成本须单列。低频样本少时明确证据有限，不能强行套用“至少30笔才运行”或凭少量盈利宣称高统计置信。

分别计算`annual_loss_pass`、`max_drawdown_pass`、`cagr_pass`及三项联合是否达到；两项风险有一项未过，则不能用高CAGR补偿。即使历史全过也只称“本口径历史达标”，不自动切换正式策略。禁止用年末采样回撤、持仓期间收益或单笔平均收益替代账户指标。

## 13. 必需验证与验收清单

### 13.1 有科学意义的针对性测试

1. **因果校准**：构造2011—2015数据，2016只使用这些年份；2016及之后的价格、估值和财报修订变化不能改变已冻结2016阈值；并列最低价取最早日期。

3. **阈值/边界**：覆盖估值恰等于`L1/L2/L3/S`、非正估值、样本不足与阈值倒置；验证Type 7分位和五点中位数可独立手算。

7. **股债门槛**：固定基日和归一化可手算；门槛只控制买入；缺债基数据只阻塞辅助case，不能换代理。
8. **红利切换**：股息率5%不买并退出；产品上市前不交易；创业板优先；红利未卖清不得买创业板；数据缺失不能假定创业板无机会。
9. **账本与执行**：分红登记/除息/支付、拆分、尾数卖出、费用、跳空、参与率、最小手数、T+1可卖数量、现金不足、公司行动撤单以及持仓连续缺价。
